- Digital Health Twin
- Appointments

- Batch and expiry metadata

- Wearable simulator

- Persistent clinical alerts
- Notification center

## Interoperability
- FHIR R4 Patient

- DiagnosticReport
- MedicationRequest
- SMART-on-FHIR demo handshake

- Patient-linked medical document records
- Real multipart file upload
- Patient QR identity payload

## UI
- Dark clinical command center
- Violet/cyan/mint accent system
- Responsive navigation
- Loading overlay
- Interactive panels, modals, empty states and action feedback
